## Official

- [M-VAVE Product Ecosystem](https://www.m-vave.com/products) — Official product overview for the whole range.
- [M-VAVE Downloads](https://www.m-vave.com/download) — Official firmware, the M-EFCS editor (PC and mobile; it supports TANK-G, TANK-B, BLACKBOX, STATION-G, STATION-B, Tank Mini, Pocket AMP, SP100, MK300 and MK20) and the updaters.
- [M-VAVE app downloads](https://www.m-vave.com/appdownload) — Official mobile app downloads.
- [Effects Description (PDF)](https://manualf.oss-cn-hongkong.aliyuncs.com/manual/Combined-Effect-Pedals/Effects-Description.pdf) — Official description of the effects of the combined-effect pedals.
- [M-VAVE × TONE3000](https://www.m-vave.com/tone3000) — Official page on the TONE3000 (NAM) collaboration.
- [M-VAVE forum](https://forum.m-vave.com/) — Official forum, including firmware update summaries.

## Custom Firmware

- [UltraRig](https://ultrarig.app) — Alternative firmware for the Tank-G v1 and v2 (public alpha, alpha10.1 with Windows and Android installers): NAM A2-Lite amp captures, an editable effects chain with parallel branches, cabinet IRs, 32 presets with four scenes each, a tuner and a browser control page. Source-available under the PolyForm Noncommercial 1.0.0 licence (not open source), unaffiliated, and an alpha: use at your own risk and keep the backup its installer makes ([releases](https://github.com/manuaguirre9/ultrarig/releases)).

## Unofficial Editors and Tools

- [Tank-G Control Center](https://github.com/CamiloFerreira/tankg-control-center) — Spanish-language preset manager for Windows, Linux and Android over USB-MIDI (and Bluetooth on the v2), speaking the M-EFCS protocol directly; v1.11.1 builds in the [releases repository](https://github.com/CamiloFerreira/tankg-control-center-releases). No licence declared.
- [MultiFX Editor](https://github.com/rmsramos/multifx-editor) — GPL-3.0 unofficial Linux desktop editor (AppImage, English and Portuguese) that writes through an undocumented protocol; back up with the official app first.
- [tank-g-controller](https://github.com/AlexandreTonin/tank-g-controller) — MIT Python desktop app and CLI (Portuguese) for editing and saving presets over USB-MIDI, with tones generated by Gemini.
- [TabJam](https://github.com/VitorCdSouza/tabjam) — Native guitar-practice app that plays Songsterr tabs, listens to the pedalboard and configures the Tank-G; no licence declared.
- [ha-mvave-tankg](https://github.com/hudsonbrendon/ha-mvave-tankg) — MIT Home Assistant (HACS) integration for the Tank-G over Bluetooth LE, built on [mvave-tankg-ble](https://github.com/hudsonbrendon/mvave-tankg-ble) (MIT Python library, also on PyPI).
- [DelayCalc](https://github.com/TecgeoBR/delaycalc-mvave) — Small web calculator (Portuguese and English) that turns a tempo into delay time and the 0–128 MIDI knob value used by compact pedals such as the Tank-G.

## File Formats and Reverse Engineering

- [m-vave-tankG-codec](https://github.com/Mekuze44/m-vave-tankG-codec) — Python encoder/decoder documenting the 21-byte `.tkg` preset format.
- [yamlvawe_tankg](https://github.com/alternativehood/yamlvawe_tankg) — Toolkit that converts Tank G v2 `.tkg` presets to and from YAML, with a web visual editor; its README says it was written with Claude Code.

## Community

- [Rockboard PedalPedia: M-VAVE Tank-G](https://www.rockboard.de/en/pedalPedia/M-VAVE/Tank-G/412105888) — Product page with a board configurator.

## Notes

- Tank-G v1 and v2 differ (Bluetooth support is on the v2): check which one a resource targets.
- Independent reviews are scarce; most coverage found is retailer listings.
- Tools that write to the pedal use reverse-engineered protocols: back up presets with the official app first.
