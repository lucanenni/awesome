## Official

- [AdrenaLinn](https://www.rogerlinndesign.com/about/adrenalinn) — Official product page: a beat-synced filter effects processor for guitar with filter sequences, random filter patterns, synced modulation/delay, 40 amp models, and programmable drumbeats; the unit is listed as discontinued.
- [AdrenaLinn support hub](https://www.rogerlinndesign.com/support/support-adrenalinn) — Central support page linking the manual, presets, FAQs, tips & tricks, MIDI spec, and software versions for AdrenaLinn III, II, and the original AdrenaLinn.
- [A3 Owner's Manual](https://cdn.prod.website-files.com/5ad24a891dee8925107423d0/5e69542a4b96309cc90a9c12_adrenalinn-iii-users-manual%2C-v302%2C-5-14-08.pdf) — Official user manual (v3.0.2, May 14, 2008), written by Roger Linn and Craig Anderton.
- [A3 Preset & Drumbeat Listing](https://cdn.prod.website-files.com/5ad24a891dee8925107423d0/5e695429681006b84c9cc4f0_adrenalinn-iii-presets---drumbeats-manual%2C-11-25-07.pdf) — Official listing of the factory presets and drumbeats (software v3.0.0, November 25, 2007).
- [A3 MIDI Specifications](https://cdn.prod.website-files.com/5ad24a891dee8925107423d0/5e6955fd0f5a6069d69d92f8_adrenalinn_iii_midi_implementation%2C_8-1-07.pdf) — Official MIDI implementation document (August 1, 2007), including the SysEx messages used to send/receive individual presets and full banks.
- [AdrenaLinn III FAQs](https://www.rogerlinndesign.com/support/support-adrenalinn-faqs) — Official Q&A covering signal routing, tuner/bypass behavior, drum/guitar output separation, amp modeling, foot controller recommendations, and MIDI sync with a live drummer.
- [AdrenaLinn 3 Tips & Tricks](https://www.rogerlinndesign.com/support/support-adrenalinn-3-tips-tricks) — Official page of usage tips for getting more out of the unit.
- [AdrenaLinn Software Versions](https://www.rogerlinndesign.com/support/support-adrenalinn-software-versions) — Firmware changelog for A3 (v3.0.0 through v3.0.3), with instructions for updating via MIDI using the SoundTower editor.
- [AdrenaLinn Upgrade Kit](https://www.rogerlinndesign.com/support/support-adrenalinn-upgrade-kit) — $99 self-install kit that upgrades an original AdrenaLinn or AdrenaLinn II to AdrenaLinn III specs (40 amp models, reverb, compressor, tuner, 200 presets/drumbeats, MIDI foot-switch/expression-pedal control).
- [Sound Examples (SoundCloud)](https://soundcloud.com/rogerlinndesign/sets/filter-sequences) — Official "Filter Sequences" demo set linked from the product page.
- [Basic Operation video](https://www.youtube.com/watch?v=xStr9lpFy9s) — Official walkthrough of the front-panel controls and basic operation.
- [Beat-synced effects video](https://www.youtube.com/watch?v=WUKVmvy_Uzk) — Official tutorial on using the beat-synced effects.

## Editor Software and MIDI Tools

- **AdrenaLinn III Web Editor** — Free, MIT-licensed web editor and librarian over Web MIDI SysEx: presets, drumbeats, library, and system parameters, with nothing to install (Chrome or Edge, USB-MIDI) and offline use once loaded.
  - [Site](https://lucanenni.github.io/adrenalinn-iii-editor/) — Hosted editor.
  - [Code](https://github.com/lucanenni/adrenalinn-iii-editor) — Source repository.
- [SoundTower AdrenaLinn III Editor](https://www.soundtower.com/adrenalinn3/index.html) — Official third-party editor/librarian ($39.95, Win/Mac) for preset and drum-beat editing, bank management, and single-preset load/save over MIDI; linked directly from the AdrenaLinn III product page and required for installing firmware updates.
- [SoundTower ADIII SE v1.0–current User Guide](https://www.soundtower.com/adrenalinn/help/SoundTower_ADIIIvX_help.pdf) — PDF user guide for the SoundTower editor covering its full feature set, including drag-and-drop `.syx` file support.
- [EurekaPROM A3 configuration](https://www.eurekasound.com/eurekaprom/a3) — $35 custom firmware/configuration for the Behringer FCB1010 pedalboard that maps five control modes to the AdrenaLinn III (effects toggling, preset/drumbeat selection, favorites, drum triggering, and expression pedals for wah/volume).
- [AdrenaLinn III Pedal Control Project](http://jeffhendricks.net/adrenalinn-iii-pedal-control-project/) — DIY project using Mididings to intercept MIDI program-change messages and auto-insert the CC command needed to switch the A3 between effects mode and drum mode, working around its single combined mode switch.

## Notes

- The AdrenaLinn III is discontinued; Roger Linn Design still lists the manual, MIDI spec, and a $99 upgrade kit (for original AdrenaLinn/AdrenaLinn II units) on its own support site as of this writing.
- Firmware updates (up to v3.0.3) are applied over MIDI using the SoundTower editor, not a standalone updater — back up your presets and drumbeats first.
- The SoundTower editor is paid third-party software, not free; it is nonetheless the officially linked and recommended tool for editing presets and installing firmware.
- Several review/manual mirrors exist on Audiofanzine, Scribd, and Internet Archive; prefer the rogerlinndesign.com-hosted PDFs above as the authoritative source.
