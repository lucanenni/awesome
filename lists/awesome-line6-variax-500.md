## Workbench (legacy)

- [Where is the Workbench software download?](https://line6.com/support/topic/39513-where-is-the-workbench-software-download/) — Community thread on locating the original Workbench: on the Downloads page, choose Variax hardware and Variax Workbench but leave the OS field on "Choose OS", otherwise version 1.75 does not appear.
- [How to install the original Workbench on Windows 10](https://line6.com/support/topic/59142-how-to-install-the-original-workbench-on-windows-10/) — Installation walkthrough; a common workaround is to untick the bundled Java install and use a separate Java runtime.
- [Variax 500 and Workbench on Windows 10](https://line6.com/support/topic/33142-variax-500-and-workbench-on-windows-10/) — Report of a working Variax 500 setup with Line 6 Monkey and the non-HD Workbench on Windows 10.
- [Workbench Software for Variax 500](https://line6.com/support/topic/27228-workbench-software-for-variax-500/) — Thread on getting the right Workbench build for the 500.
- [Unable to install Workbench on Mac](https://line6.com/support/topic/26686-unable-to-install-workbench-on-mac/) and [Workbench version for Mavericks](https://line6.com/support/topic/6775-workbench-version-for-mavericks/) — Mac compatibility threads: reports range from a Java 6 plus installer-check workaround on macOS Sierra to keeping an old Mac on Mountain Lion.
- [Just got an old Variax. What software do I use in 2022?](https://line6.com/support/topic/64233-just-got-an-old-variax-what-software-do-i-use-om-2022-to-play-with-it/) — Recent community answer on the current state of the legacy toolchain.
- [Variax Workbench manual](https://www.vguitarforums.com/smf/index.php?topic=14452.0) — Copy of the original Workbench manual hosted on VGuitar Forums.
- [Vettaville Workbench FAQ](https://www.vettaville.nl/vvworkbench5.htm) — Long-running Dutch fan site with Workbench FAQs and notes.
- [Line 6 Variax Workbench (Sound On Sound review)](https://www.soundonsound.com/reviews/line-6-variax-workbench) — Contemporary review of the original software.
- [Line 6 Intros Free Variax Workbench Software (Synthtopia)](https://www.synthtopia.com/content/2005/08/28/line-6-intros-free-variax-workbench-software/) — 2005 announcement of the free Workbench.

## Notes

- The original Workbench (1.75) supports the Variax 300, 500, 600, and 700. **Workbench HD is a different program for the JTV, Standard, and Shuriken guitars** and does not connect to the first-generation guitars; HD 2.0 firmware presets and original patches are not interchangeable.
- The guitars need a Line 6 USB interface (or a POD/Vetta with a VDI input) to talk to the computer; Line 6 has said there will be no further development of the original Workbench.
- Compatibility with current Windows and macOS is anecdotal and based on forum reports, mostly several years old; Windows 11 results were not found.
- Many forum threads and attached archives are over a decade old, so some links or downloads may no longer work.
