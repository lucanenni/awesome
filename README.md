# Awesome Music Gear

[![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> A collection of curated lists ("awesome lists") of official and community resources for guitar multi-effects processors, amp modelers, synthesizers, and related music gear.

Each device has its own list with official downloads/manuals, unofficial editors and software, preset packs, and community documentation. See the [Contributing](#contributing) section if you'd like to add a resource or a new device list.

## Contents

## Contributing

Contributions are welcome! Each list has its own `Contributing` section with guidance on what to include (tested device, firmware version, operating system, and a short description of the resource). To add a new device, create a new `lists/awesome-<device>.md` file following the structure of the existing lists and add it to the Contents above.
